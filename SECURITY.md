# Security Policy

This policy applies to every repository under [therogueroadmap](https://github.com/therogueroadmap).

## Supported versions

Only the latest released version of each project receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the **Security** tab of the affected repository and
choose **Report a vulnerability**. The report stays private between you and the maintainer.

Include, when you can:

- the repository and the version, tag or commit affected;
- the steps to reproduce the problem, or a proof of concept;
- the impact you expect.

## What to expect

- An acknowledgement within 7 days.
- An assessment and, when the report is confirmed, a fix or a mitigation plan.
- Credit in the release notes once the fix is published, unless you prefer to stay anonymous.

Please give the maintainer a reasonable time to publish a fix before disclosing the problem.
